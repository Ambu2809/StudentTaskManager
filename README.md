
# StudentTaskManager (TaskForge)

## 1. Project Introduction
StudentTaskManager is a web-based task management application designed to help students organize their daily and weekly tasks. It provides a dashboard to view tasks and track their completion status.

## 2. Objectives
- To organize daily and weekly student tasks.
- To add new tasks and mark them as completed.
- To display task statistics and completion progress.
- To learn Git and GitHub version control.
- To integrate Jenkins as a DevOps automation tool.

## 3. Technology Stack
- HTML — Website structure
- CSS — Website design and styling
- JavaScript — Task functionality
- Git — Version control
- GitHub — Source code hosting
- Jenkins — DevOps pipeline automation

## 4. Features
- Student task dashboard
- Add and manage tasks
- Mark tasks as completed
- Display total, incomplete, and completed task counts
- Display task completion percentage
- Day-wise and week-wise task organization (if enabled in the final code)
- Incomplete task reminder banner (website display, if implemented)

## 6. How to Run the Project
1. Download or clone the GitHub repository.
2. Open the StudentTaskManager folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Alternatively, use the Live Server extension in VS Code.
5. Test the available task management features.
